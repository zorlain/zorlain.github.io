GitHub에서 문의 남기기

GitHub 계정이 필요합니다. 이슈는 공개되므로 개인정보나 비밀번호, 개인 파일은 적지 마세요.

문의할 때 알려 주시면 좋은 내용

  • 사용한 도구의 이름과 주소
  • 어떤 값을 입력했고, 어떤 결과를 기대했는지
  • 사용 중인 기기와 브라우저(예: 안드로이드 크롬, 아이폰 사파리)
  • 화면에 나온 오류 문구
