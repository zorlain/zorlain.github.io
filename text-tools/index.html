자주 묻는 질문

글자수 공백 포함과 제외는 어떻게 다른가요?

공백 포함은 띄어쓰기와 줄바꿈까지 모두 세고, 공백 제외는 공백 문자를 뺀 글자만 셉니다. 자기소개서나 과제처럼 글자 수 제한이 있을 때 기준에 맞는 값을 확인하세요.

바이트 수는 어떤 기준인가요?

UTF-8 기준으로 계산합니다. 영문과 숫자는 1바이트, 한글은 보통 3바이트로 셉니다.

대소문자와 공백 정리는 무엇을 할 수 있나요?

대문자·소문자·Title Case 변환, 줄 앞뒤 공백 제거, 중복 줄 제거, 빈 줄 제거, 연속 공백 줄이기, 한 줄로 합치기를 지원합니다.

입력한 글이 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서 이루어지고 입력한 글은 서버로 전송되지 않습니다.
